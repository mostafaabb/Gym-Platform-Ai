# 🚀 GymFlow AI: Platform Overview & Technical Documentation

GymFlow AI is an enterprise-grade, AI-driven gym management and fitness coaching platform. It leverages cutting-edge Computer Vision and Large Language Models to provide real-time coaching, business intelligence, and a premium user experience.

---

## 🏛️ System Architecture

### 1. Backend (FastAPI)
- **High-Performance API**: Built with FastAPI for asynchronous I/O operations.
- **Database Architecture**: SQLAlchemy (Async) with PostgreSQL for scalable data persistence.
- **Security**: 
  - JWT (JSON Web Tokens) for session management.
  - Role-Based Access Control (RBAC) covering Super Admin, Gym Owner, Trainer, and Member.
  - Cryptographically secure 6-digit verification codes for sensitive operations (e.g., password reset).

### 2. Frontend (Next.js 15+)
- **Modern UI/UX**: Built with React 19 and Next.js 15, featuring a "Glassmorphism" aesthetic.
- **Animations**: Fluid interactions using `framer-motion`.
- **Data Visualization**: Real-time business and fitness analytics using `recharts`.
- **State Management**: Optimized React hooks and custom service layers for real-time data sync.

## 🤖 AI & Computer Vision Capabilities

### 1. AI Voice Coach
- **Real-Time Interaction**: Bi-directional communication via WebSockets.
- **Context-Aware Coaching**: The AI knows your fitness goals, experience level, and current workout state.
- **Dynamic Feedback**: Provides verbal cues for reps, rest times, and motivation.

### 2. Pose Analysis Engine & Body Map
- **MediaPipe Integration**: Real-time 33-point body landmark tracking.
- **Interactive Body Map**: High-fidelity SVG visualization of muscle training volume distribution.
- **Form Correction**: Detects common errors and triggers instant visual/audio alerts.
- **Performance Scoring**: Calculates a "Form Score" out of 100 for every exercise set.

### 3. Gamification System
- **Leaderboards**: Competitive rankings based on consistency and form.
- **Achievement Engine**: Automated unlocking of milestones like "Consistency King" and "First Step."
- **Progressive Scoring**: Real-time point updates via `GamificationService`.

## 🏁 Deployment & Setup

To run the platform locally or in production:
1. **Environment**: Configure `.env` with `DATABASE_URL` and `OPENAI_API_KEY`.
2. **Backend**: `uvicorn backend.main:app --reload`
3. **Frontend**: `npm run dev`
4. **Email**: Configure `SMTP_HOST`, `SMTP_USER`, and `SMTP_PASSWORD` for live emails.
